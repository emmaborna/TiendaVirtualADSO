# Tienda Virtual

## Objetivo
Crear una tienda virtual que permita a los clientes consultar productos y realizar compras por internet de forma fácil y rápida.

## Funciones
1. **Consultar productos:** Mostrar los productos disponibles y sus precios.
2. **Realizar compras:** Permitir a los clientes seleccionar productos y hacer pedidos.
